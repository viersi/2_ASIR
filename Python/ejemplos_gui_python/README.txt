# Ejemplos de Interfaces Gráficas en Python
Este paquete contiene ejemplos básicos de distintas librerías GUI en Python.

## Contenido
1. Tkinter
2. PyQt6
3. PySide6
4. Kivy
5. PySimpleGUI
6. WxPython
7. Flask
8. Streamlit
9. Flet
10. Dear PyGui
11. CustomTkinter

Cada archivo `.py` muestra una ventana o interfaz básica con un botón de saludo.

### Ejecución
- Ejecuta con: `python nombre_archivo.py`
- Algunos requieren instalación previa:
  ```bash
  pip install pyqt6 pyside6 kivy PySimpleGUI wxPython flask streamlit flet dearpygui customtkinter
  ```
